# Contributing

This repository publishes curated snapshots of privately developed source.
Public pull requests are disabled and are not accepted. See
[DEVELOPMENT.md](DEVELOPMENT.md) for the development and release model.

Use [issues](https://github.com/noisefloor-oss/sdlc/issues) to report bugs or
propose changes. For bugs, include the CLI version, operating system, steps to
reproduce, and expected and actual behavior. For proposals, describe the
problem, evidence from real use, and the smallest change that would help.
Remove credentials, private project details, and other sensitive data from
examples and output. Filing an issue does not commit the maintainer to a fix
or timeline.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
